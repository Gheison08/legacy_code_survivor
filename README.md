# LEGACY CODE SURVIVOR

## Como empezar:
- Clonar Repo: Ejecutar comando `git clone https://github.com/Gheison08/legacy_code_survivor.git`
- Instalar dependencias: Ejecutar `py -m pip install flask`
- Levantar servidor: Ejecutar `py .\app.py` o `python .\app.py` en la raíz del proyecto.
- Disfrutar: Acceder al enlace `http://127.0.0.1:5000` o `http://localhost:5000` en cualquier navegador para iniciar el juego.
